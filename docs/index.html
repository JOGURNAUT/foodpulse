FoodPulse

A food-delivery warehouse, and a promise that does not know what it promised.

S3 → untyped raw → dbt staging → 11 marts, addressed by URI so the same models run against a local DuckDB file or Snowflake. Two facts are incremental, one dimension keeps its history as a type-2 snapshot, and an AI layer sits on top, tagged so the core warehouse never depends on it.

  • 2,000,000 orders
  • 11 marts
  • 84 tests
  • 0.45% defect rate

The finding

The delivery promise uses one flat 45 minutes for every cuisine. Kitchen time is a property of the dish: a biryani is cooked to order, a dessert is plated. That promise breaks 37.1% of the time on biryani and 0.4% of the time on desserts. A single threshold across populations with different floors is wrong at both ends.

Architecture

CSV to S3 to Snowflake RAW, dbt staging and marts, an AI layer tagged apart from the core build, and the Airflow DAG that runs all of it.

Results

SLA breach by cuisine, what the warehouse threw out and why, and the incremental merge measured against a full rebuild.

What each piece is doing

Named by the job it does, so the stack list is not the first thing you have to decode.

  • staging Six views that type, deduplicate and flag every source. Raw stays untyped so a bad value fails a named test, not a load.
  • fct_orders Incremental: a daily run merges new and late-arriving rows on a trailing window instead of rebuilding two million orders.
  • snap_restaurant Type-2 snapshot, so an order from before a restaurant moved cities still joins to the city it actually happened in.
  • mart_data_quality Every excluded row, counted under the rule that excluded it. "We load clean data" is a claim with nothing behind it without it.
  • Airflow One daily DAG: copy into raw, build and test the core models, enrich reviews, then build the AI-tagged marts on top.
  • ai/text_to_sql.py A model writes SQL against the warehouse; a guard restricts it to one SELECT over an allowlist, checked by 20 tests.

The data is generated. A seeded script injects six defect classes on purpose (orphaned orders, duplicate exports, withheld ratings, currency errors) because a clean dataset cannot exercise a quality gate. What is not circular is the shape: a single SLA across populations with different floors is wrong at both ends, and a test asserts that ordering survives a change of seed.
